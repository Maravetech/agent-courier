# Changelog

## 0.2.0

- Two-way Claude ⇄ Codex: `watch` blocks until any listed session finishes a turn (state returns to idle) so the sender wakes and reads the reply; meant to run in the background.
- `--app claude`: read-only back end for Claude desktop sessions (find/status/verify/wait/watch/locate/compose).
- `ui-send` now requires `--expect-tab` (security review: the tab check could be skipped).
- Loop rules: only `【投递】` triggers work and a reply; `【回复】` never auto-replies; 5-delivery cap.

## 0.1.1

- Plugin icon (`.claude-plugin/icon.png`, generated by `assets/make_icon.py`, needs Pillow).
- Install via skills.sh (`npx skills add`).

## 0.1.0

- Front-end delivery into any Codex app session via Claude Computer use (background) or cua-driver accessibility calls.
- Back-end delivery proof and reply reading from `~/.codex` logs, including archived sessions.
- Identity tokens for messages and replies; draft protection; tab check.
- CLI fallback via `codex exec`.
