# Changelog

## 0.4.0

- Optional macOS bird overlay anchors 2 pt before Claude or Codex sidebar conversation numbers through Accessibility. Each visible pair has two rings, one straight line, a three-frame bird that flies for 2.5 seconds, and restrained CoreGraphics particles. The resident SkyLight renderer uses small click-through windows and no AppKit; it draws its own icon and opens a separate AppKit pair panel on demand. The ten most recently active pairs display, while the panel lists all pairs and lets users connect or disconnect existing pairs. A disconnected pair blocks delivery with exit code 5. The renderer exits after the last pair disappears. Signed installation, physical icon click, and Launch at Login registration remain unverified.
- `overlay pair` supports Computer use deliveries; `ui-send`, `verify`, `wait`, and `watch` update the visual state automatically. `COURIER_OVERLAY=0` disables it.
- Per-app AX rules, visible-row filtering, duplicate-frame selection, and `locate.log` track anchors. A test-only focus probe records the overlay's PID, foreground app, and key-window state.
- Use the shared brand bird icon from the local 0.2.2 icon update; the remote release was already 0.3.0 when this feature branch was started.

## 0.3.0

Fixes from an independent security review. Upgrade from any earlier version.

Breaking:

- `wait` exits non-zero when the turn was aborted, when there is no reply, or when the reply header does not match the delivery.
- `ui-send` needs the exact target session, refuses ambiguous titles, and re-reads the tab and the input box right before sending.

Changes:

- H3: UI delivery is bound to the exact session; the draft and tab are checked again after writing and before sending, so a tab switch in between stops the send and keeps the draft.
- A2: `wait` is anchored to the delivered user message instead of a wall-clock `--since`, so starting it late no longer misses a turn that has already ended.
- A3: `watch --stream` prints one line per state change (started, completed, aborted, waiting) for callers that run it in the background.
- M1: Aborted turns and malformed or mismatched reply headers no longer count as success.
- Multi-line input box values read through accessibility are decoded before the draft check.
- M5: CI actions pinned to commit SHAs, with `permissions: contents: read`.
- L1: README, SKILL.md and PREREQUISITES.md match the code.

## 0.2.0

- Two-way Claude ⇄ Codex: `watch` blocks until any listed session finishes a turn (state returns to idle) so the sender wakes and reads the reply; meant to run in the background.
- `--app claude`: read-only back end for Claude desktop sessions (find/status/verify/wait/watch/locate/compose).
- `ui-send` now requires `--expect-tab` (security review: the tab check could be skipped).
- Loop rules: only `【投递】` triggers work and a reply; `【回复】` never auto-replies; 5-delivery cap.
